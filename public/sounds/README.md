# Ringtone Audio File

## Required File
Place a ringtone audio file here named `ringtone.mp3`

## Options:

### Option 1: Use a Free Ringtone
Download a free ringtone from:
- https://www.zedge.net/ringtones
- https://www.freesound.org/
- https://mixkit.co/free-sound-effects/phone/

Save it as `ringtone.mp3` in this folder.

### Option 2: Use Browser's Default
If no ringtone file is provided, the system will still work but without audio.
The visual notification will still appear.

### Option 3: Create Your Own
You can record your own ringtone or use any MP3 file.
Just name it `ringtone.mp3` and place it here.

## File Location
```
public/sounds/ringtone.mp3
```

## Recommended Settings
- Format: MP3
- Duration: 3-5 seconds (will loop)
- Volume: Moderate (not too loud)
- Bitrate: 128kbps or higher

## Testing
After adding the ringtone:
1. Restart your server
2. Initiate a call
3. The ringtone should play when receiving a call
